# 24 November 2026 in one image

An editorial poster summing up the world news of Tuesday 24 November 2026. The repository ships the finished PNG and a small Node program that copies it to `/output/entry.png`.

The lead story is Ukraine's naval-drone strike on a Russian corvette in Benghazi. Four short panels cover Jensen Huang's return to Nvidia, the collapse of COP31, the Strait of Hormuz blockade and the Indonesian factory fire. A map strip and three tickers add breadth without crowding the frame.

The source illustration is `render.html`, an SVG drawn for this entry and rendered to `entry.png` at 1024 by 1024 pixels. No network request is made at runtime.
